Quick Start

Install via npm and create your first payment invoice in seconds. Full TypeScript support with comprehensive type definitions.

  • ✓ Wallet detection (Xverse, Unisat, Phantom)
  • ✓ QR code generation
  • ✓ Transaction confirmation tracking
  • ✓ Webhook callbacks
  • ✓ MCP server integration
// npm install mibtc-one import { MiBTCPay } from 'mibtc-one'; const pay = new MiBTCPay({ merchantId: 'your-id', network: 'mainnet' }); // Create a payment invoice const invoice = await pay.createInvoice({ amount: 100, // 100 miBTC currency: 'MIBTC', description: 'Premium access', callbackUrl: 'https://your.api/webhook' }); // Returns: { id, qrCode, address, amount } console.log(invoice.qrCode);
